# Привет, я ametistovv 👋

**Python-разработчик и сборщик всего, что живёт в Telegram и в браузере.**
Делаю ботов, веб-сервисы и игры — от идеи до запуска на сервере.

---

### Чем занимаюсь

- 🤖 **Telegram-боты** — aiogram 3, long polling, админ-панели, запись клиентов, приём заявок
- 🛠 **Веб-сервисы** — Node.js, SQLite, авторизация, оплата и подписки, Mini Apps
- 🎮 **Браузерные игры** — чистый JavaScript, Canvas, WebAudio, интеграция с Яндекс Играми
- 🧠 **Локальные LLM** — подготовка датасетов, LoRA-дообучение, запуск моделей через llama.cpp
- 🦀 **Rust** — портирование ботов и работа с асинхронным кодом
- 🐧 **Linux и деплой** — systemd, Nginx, VPS, резервные копии и мониторинг
